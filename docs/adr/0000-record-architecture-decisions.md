# ADR 0000: توثيق قرارات المعمارية

- **الحالة:** مقبول
- **التاريخ:** 2026-11-18

## القرار

كل قرار معماري يُوثَّق في ملف واحد تحت `docs/adr/` بالشكل التالي: السياق، القرار،
الآثار، ومتى تُراجَع. الترتيب رقمي متسلسل.

## لماذا

الوكلاء يغيّرون الشيفرة بسرعة. بلا سجل قرارات، يصبح المستودع مجموعة اختيارات
لا أحد يعرف لماذا اتُّخذت، ومن يقدر يراجعها. القرار المكتوب هو ما يحوّل
«الكود يقول» إلى «القرار يقول».

## الآثار

- كل قرار جديد يزيد ملفاً واحداً.
- المراجعة تُقرأ القرارات قبل الشيفرة.
