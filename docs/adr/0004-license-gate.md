# ADR 0004: بوابة التراخيص تحجب أي تبعية غير مسجّلة

- **الحالة:** مقبول
- **التاريخ:** 2026-11-18

## السياق

الترخيص يفشل بعد الدمج لا قبله: عندها يكون الكود في التاريخ، وال.Remove
أصعب من الرفض.

## القرار

1. كل تبعية في `pyproject.toml` يجب أن تكون مسجّلة في
   `docs/provenance/dependencies.json` بقرار (allow/deny) ورخصة ومصدر وتبرير.
2. `scripts/check_licenses.py` في كل خط أنابيب، قبل الاختبارات.
3. القاعدة: **نقبل الكود، نرفض الترخيص**. GPL-3.0 وAGPL-3.0 وFSL وغير OSI
   لا تدخل البناء. الاستثناء: خدمة معزولة لا يُدمج كودها ولا تُنشر أدواتها.
4. التبعيات المرفوضة تُبقى مسجّلة مع سبب الرفض — حتى لا يُعاد اقتراحها بعد
   ستة أشهر بلا نقاش.

## الآثار

- إضافة تبعية جديدة = سطر JSON + مراجعة. هذا هو الثمن المقصود.
