# حزمة التسليم

ما يُسلَّم، ولماذا هذا الشكل. الحزمة تُبنى بأمر واحد:

```bash
python3 scripts/build_delivery_pack.py --out dist/
```

## ما في الحزمة

| القسم | المحتوى | ما يثبته |
|---|---|---|
| `source/` | الشيفرة كما هي: `src` و`tests` و`docs` و`scripts` و`examples` | ما رُئي هو ما سُلِّم — بلا «شجرة نظيف» ولا لقطات شاشة |
| `reports/gates.txt` | ثوابت المستودع | لا أسرار، لا محارف مسرّبة، الشيفرة تُصرَّف، الكتالوج متّسق |
| `reports/licenses.txt` | بوابة التراخيص | كل تبعية لها قرار ورخصة وتبرير |
| `reports/catalogue.txt` | فحص الكتالوج | 8 نطاقات · 24 قدرة · 4 استدعاءات، والوثيقة مطابقة |
| `reports/acceptance.txt` | شواهد AC-01..AC-20 | كل معيار: مُثبَت بنوعه (حيّ/آلي)، مع سبب النقص لما لم يُثبَت |
| `reports/evals.txt` | مجموعات التقييم | المخرج يفي بالمواصفة |
| `reports/load.txt` | مقياس الحمل | لا خطأ واحد، p95 تحت السقف |
| `manifest.json` | بصمة إعادة البناء + فهرس التقارير | الربط بين ما سُلِّم وما يثبته |

## البصمة

`rebuild_hash` في `manifest.json` بصمة sha256 لكل ملفات المصدر بمساراتها
النسبية. **نفس الشجرة ⇒ نفس البصمة**، وأي تعديل يغيّرها. هذه هي آلية
AC-19: إعادة البناء من الإصدارات قابلة للفحص آلياً، لا بالقول.

## ما لا يدخل الحزمة

- الأسرار والمفاتيح: **أبداً**. المفتاح في مدير الأسرار، والسجل يكتب
  أسماء المتغيّرات لا قيمها.
- `.git` وسجلّات البناء المؤقتة: الحزمة تحمل الشيفرة والحلقة، لا تاريخ
  git.
- البيانات الحقيقية: ما لم يُنتج بعد (يتطلّب مفتاحاً). الحزمة تذكر
  ذلك صراحةً بدل أن تُظهر artefact فارغاً.

## سلسلة التسليم

1. `validate_repo.py` + `check_licenses.py` + `catalogue_report.py --check`
   + `verify_acceptance.py` + `eval_check.py` + `load_check.py` — **كلها** خضراء.
2. `build_delivery_pack.py` — يبني الحزمة ويسجّل البصمة.
3. المراجع يشغّل الأوامر نفسها على الحزمة ويقارن البصمة.
4. أي اختلاف ⇒ **يوقف**، ولا يُفسَّر براحة.
