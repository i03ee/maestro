# النموذج المحلي — الطبقة الأولى

كل سلسلة في MAESTRO تبدأ بالنموذج المحلي ثم تنزل إلى الواجهة ثم الاحتياطي.
وسبب البدء محلي: **صفر تكلفة، وبيانات لا تغادر جهازك**.

## ما الذي يشتريه فعلاً

| | محلي | واجهة |
|---|---|---|
| تكلفة المخرج | **صفر** | $0.006 لكل 8000 رمز (DeepSeek Flash، هدوء) |
| خصوصية البيانات | **تبقى على جهازك** | تخرج إلى المزوّد |
| جودة المهام الصعبة | أقل | أعلى |
| توفّر الخدمة | متى شغّلت الخادم | متاح دائماً |

لذلك: **الطبقة المحلية للطبقات الأولى (الكتالوج، التوثيق، الاختبارات)،
والقدرات الحرجة بنموذجين على الأقل** — المحلّي لا يُغني عن الاتفاق.

## التشغيل

```bash
# 1) شغّل خادماً محلياً متوافقاً مع OpenAI (مثال: Ollama)
ollama serve
ollama pull qwen2.5-coder:7b

# 2) تأكّد أن البيئة سليمة
PYTHONPATH=src python3 -m maestro doctor
#    ⇒ سطر «النموذج المحلي» يذكر وجوده وعدد نماذجه

# 3) شغّل قدرة بسلسلة تبدأ بالنموذج المحلي
export MAESTRO_LOCAL_BASE_URL=http://127.0.0.1:11434/v1
```

عنوان الخادم الافتراضي `http://127.0.0.1:11434/v1`، ويُغيَّر بالمتغيّر
`MAESTRO_LOCAL_BASE_URL`.

## عند غياب الخادم

`maestro doctor` يقول ذلك **صراحةً** («لا خادم محلي — الطبقة المحلية غير
متاحة») ولا يعدّه فشلاً: المشروع يعمل بلا نموذج محلي، لكن لا يُظنّ أن
الطبقة موجودة وهي ليست.

## ما لا يغيّره النموذج المحلي

- **القدرات الحرجة تبقى لنموذجين.** الاتفاق (2 من 3) شرط في العقد IR-12، لا
  خيار تشغيلي.
- **الميزانية تُحسب على السلسلة كلها** (`maestro estimate`) — المحلي يصفر،
  والباقي يُحسب.
- **العيّنات الذهبية والدّقة** لا تتغيّر بتغيّر النموذج: العقد يبقى
  كما هو — والمُدقِّق يقيس المخرج لا المصدر.
